## Excluded material

- The live Tauri audit restored personal browser content. It is not copied into this project,
  rendered, or distributed.
- No stock music, sound-effect library, commercial font service, public GitHub screenshot, or
  competitor brand asset is used.
- The removed Mission Control and Memory dashboard implementations are not represented as current
  product functionality. The campaign film's mission and continuity sequences are shot on Swarms and
  Agent Resume instead; see `docs/CAMPAIGN_FILM.md`.
- The Swarm work view's Memory tab is not filmed. Its read path is live, but nothing outside
  migration tests writes `memory_items`, so a real installation shows its empty state — rendering it
  populated would present an unshipped capability as shipped.
- The `.swarm-model-defaults` row of the Swarm overview is not filmed, because it has no styles in
  the product's stylesheet and paints as unstyled markup in the shipping app.
- The campaign film's opening sequence draws generic tool surfaces — "Terminal", "Agent session",
  "Pipeline", "Review". No competitor's chrome, branding, or product name appears in it.

## Open rights question — ElevenLabs stems

The campaign score's twelve source stems were generated through the ElevenLabs sound-generation API
on an account that reports `"tier": "free"`.

ElevenLabs grants commercial usage rights on its paid plans; free-tier output is generally licensed
for non-commercial use with attribution. A brand film is unambiguously commercial use. **This must
be resolved before the film is published**, by one of:

- upgrading the account to a paid plan, which grants commercial rights, and regenerating the stems
  on that key (`npm run stems:campaign` re-fetches anything deleted from `public/audio/stems/`);
- confirming in writing with ElevenLabs that the existing generations carry commercial rights; or
- replacing the stems with commissioned or owned recordings, which the arrangement supports without
  any change to `build-campaign-score.mjs` — it reads whatever is in `public/audio/stems/`.

The arrangement, the beat map, the sound-design placement and every other asset in this project are
first-party and unaffected.

Note also that ElevenLabs' Music API (`/v1/music`), which composes a finished track rather than
textures, is itself gated to paid plans and returned `402 paid_plan_required` on the key used here.

## The gate film's score

`public/audio/paralith-gate-score*.mp3` are first-party in full and carry no third-party licence
condition of any kind. They are synthesised by `scripts/build-gate-score.mjs` from oscillators and
seeded pseudo-random noise — no samples, no stems, no sound library, no generation API, and no
network access. `ffmpeg` encodes the finished buffer and does nothing else.

This is deliberate. The campaign score's ElevenLabs stem licence is unresolved for commercial use
(see above), and a new film built on the same stems would have inherited that blocker. The gate
film can be published without waiting for it.

Everything else the gate film uses is already covered above: the PARALITH mark and wordmark from
the repository logo pack, and Chakra Petch and JetBrains Mono under the SIL Open Font License.
